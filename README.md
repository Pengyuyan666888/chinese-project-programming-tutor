# Project Programming Tutor

一个面向编程初学者的中文 Agent Skill。它用**真实项目、小段代码和每轮 2～3 个相关知识点**进行教学，避免一次展示大量代码和文字造成的信息过载。

本项目改编自 [USKhokhar/tutor](https://github.com/USKhokhar/tutor)，保留其项目式学习和个性化教学思想，并针对中文初学者重新设计了讲解节奏。

## 为什么制作这个 Skill

很多 AI 编程导师会一次解释大段代码：

- 新概念过多，难以记住前面的内容；
- 一屏代码和文字容易产生畏难心理；
- 代码脱离真实使用场景，不容易理解为什么要这样写；
- 只解释语法，不解释执行过程、设计原因和必要的底层原理。

这个 Skill 尝试在“讲得太多”和“推进太慢”之间取得平衡。

## 核心特点

- **适中的学习粒度**：默认每轮讲解 2～3 个紧密相关的小知识点。
- **真实项目驱动**：围绕具有实际用途的项目学习，而不是堆砌孤立语法。
- **小段代码**：每次只展示当前目标所需的代码，复杂内容分轮解释。
- **解释执行过程**：追踪输入、变量变化、控制流和输出。
- **讲清为什么**：不仅说明代码做什么，也解释为什么这样设计。
- **必要时深入原理**：结合当前问题介绍内存、解释器、数据结构、网络等底层知识。
- **学习者控制节奏**：可以随时要求继续、回顾、深入原理、加快或直接查看答案。
- **友好的反馈**：不默认学习者熟悉术语，不因答错施压。

## 每轮教学结构

一次典型的教学轮次包含：

1. 当前项目目标；
2. 一小段相关代码；
3. 2～3 个相关知识点；
4. 实际运行效果和当前边界；
5. 一个自然的停止点，由学习者决定下一步。

例如，学习 Python 时可以围绕一个真实的命令行待办工具，逐步完成：

- 接收并显示任务；
- 用列表保存多项任务；
- 使用循环展示任务；
- 将数据保存到文件；
- 添加删除、完成状态和异常处理。

## 安装

### DeepSeek Harness

将本仓库作为一个目录放入 DSH 的用户 Skill 根目录：

```text
~/.dsh/skills/project-programming-tutor/
├── SKILL.md
├── README.md
└── LICENSE
```

Windows 默认路径通常是：

```text
C:\Users\<你的用户名>\.dsh\skills\project-programming-tutor
```

DSH 的本地 Skill 提供器会发现目录中的 `SKILL.md`。安装后可在新对话中直接说：

> 使用 project-programming-tutor，通过真实项目教我 Python。

也可以自然地表达：

> 我是初学者，想通过做一个待办事项程序学习 Python，每次不要讲太多。

### 其他支持 Agent Skills 的工具

把 `SKILL.md` 放入对应工具的技能目录。不同工具的目录约定可能不同，请参考该工具当前版本的文档。

## 使用示例

```text
通过制作一个真实可用的记账程序教我 JavaScript。
我没有编程基础，每轮讲 2～3 个知识点。
请解释代码执行时变量如何变化，以及为什么这样设计。
```

```text
帮我阅读这个项目。先概览整体结构，再每次选一小段关键代码讲解。
如果涉及底层原理，请先讲与当前代码直接相关的部分。
```

## 设计原则

这个 Skill 不把“每轮 2～3 个知识点”当作僵硬限制。内容非常简单时可以适当加快；学习者感到困惑或疲劳时则进一步拆分。目标不是覆盖尽可能多的知识，而是让学习者理解当前代码，并能把知识应用到项目的下一步。
